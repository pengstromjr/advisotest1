# Decisions

Record important product, technical, and company decisions here.

## 2026-04-29 — Company focus

Adviso will initially focus on UC Davis academic advising, with Phillip Engstrom Jr. as founder/lead developer and Olivia Mehta as cofounder.

## 2026-04-29 — Knowledge management

Use Slack as the fast capture and command layer, and GitHub Markdown docs in `/docs` as the durable source of truth. Google Docs can be used later for polished external-facing documents.

Rationale:
- Pablo can read/write GitHub Markdown directly.
- Docs version with code.
- Slack notes can be distilled into structured docs and issues.
- Avoids early Google Drive permission complexity.

## 2026-04-29 — Safety/product posture

Adviso should not present itself as an official UC Davis advisor unless formally approved. It should distinguish official requirements from interpretations or uncertain assumptions.
