# Product Roadmap

## Current Product Direction

Adviso is an AI-powered academic advising assistant, initially focused on UC Davis students who need fast, personalized academic planning support without waiting for a human advisor.

The product should feel premium, clean, minimalist, trustworthy, and more like a thoughtful academic planning workspace than a generic chatbot.

## MVP Capabilities Observed

- Student onboarding
- Major/year selection
- Optional unofficial transcript scan
- Optional blocked/busy time setup
- AI chat with course/planning context
- Degree audit views
- Schedule planning and health checks
- Course cards and prerequisite chains
- Section lookup
- Grade/professor/course data usage

## Near-Term Priorities

1. **Trust and correctness**
   - Make the assistant clearly explain reasoning.
   - Distinguish official catalog facts from inferred advice.
   - Avoid pretending to be an official UC Davis advisor.

2. **Student planning workflow**
   - Make onboarding lead naturally into a first useful plan.
   - Improve schedule generation and degree audit clarity.
   - Highlight blockers, missing prerequisites, and quarter-by-quarter next steps.

3. **Data reliability**
   - Verify course, section, prerequisite, and program requirement data.
   - Add source/citation patterns where possible.
   - Track known data gaps.

4. **Polish and credibility**
   - Tighten UI details.
   - Make outputs concise, confident, and actionable.
   - Build trust through transparency and guardrails.

## Later Priorities

- Pilot strategy for UC Davis students
- User interview loop
- Analytics and feedback capture
- Institution-facing version
- Compliance review
- Fundraising/investor narrative
